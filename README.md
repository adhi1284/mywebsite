# Wonder Cheats landing page

A static landing page using HTML, CSS, and JavaScript. The current page is branded **Wonder Cheats** and includes a hero section, navigation, mobile-menu interaction, and download/community links.

## Project structure

| File | Purpose |
| :--- | :--- |
| [index.html](index.html) | Page markup and embedded JavaScript. |
| [styles.css](styles.css) | Page styles. |

## Technology

HTML · CSS · JavaScript

## Scope

This repository contains the landing-page source. Its existing content refers to third-party gaming tools and includes Celery-related metadata and links. It should be evaluated as a website implementation; this repository does not establish ownership of those third-party tools.

## Preview

Open `index.html` in a modern browser to inspect the page. Some images and links depend on external services and may change independently of this repository.
